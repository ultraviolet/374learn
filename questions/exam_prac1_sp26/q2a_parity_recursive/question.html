The *parity* of a bit-string $w$ is $\mathbf{0}$ if $w$ has an even number of $\mathtt{1}$s, and $\mathbf{1}$ if $w$ has an odd number of $\mathtt{1}$s. For example: $$\mathit{parity}(\varepsilon) = 0 \qquad \mathit{parity}(\mathtt{0010100}) = 0 \qquad \mathit{parity}(\mathtt{00101110100}) = 1$$ Give a *self-contained*, formal, recursive definition of the $\mathit{parity}$ function. (In particular, do **not** refer to $\#$ or other functions defined in class.)
