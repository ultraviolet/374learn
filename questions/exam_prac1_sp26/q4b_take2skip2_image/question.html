Recall that $\mathit{take2skip2}(w)$ takes the first two symbols of $w$, skips the next two, takes the next two, skips the next two, and so on. Given a language $L \subseteq \{0,1\}^*$, define $$L' = \{\mathit{take2skip2}(w) \mid w \in L\}.$$ We assume we have a DFA $M = (Q, \{0,1\}, \delta, s, A)$ that accepts $L$. Construct an NFA $M' = (Q', \{0,1,\varepsilon\}, \delta', s', A')$ that accepts $L'$. The key idea: $M'$ reads an image string $x = \mathit{take2skip2}(w)$ and must non-deterministically **guess** the two skipped symbols per block (since they were removed by the transformation).
