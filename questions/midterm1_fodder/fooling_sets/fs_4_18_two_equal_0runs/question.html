{{{params.html}}} Use the fooling set $\{0^n\mathtt{1} \mid n \geq 1\}$. The suffix $\mathtt{0}^j$ gives $0^i\mathtt{1}\mathtt{0}^j$: this has two 0-runs of lengths $i$ and $j$. The string is in $L$ iff $i = j$. So the suffix $\mathtt{0}^i$ distinguishes $0^i\mathtt{1}$ from $0^j\mathtt{1}$ for $i \neq j$.
