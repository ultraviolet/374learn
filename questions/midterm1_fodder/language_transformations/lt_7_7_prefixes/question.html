Define the transformation $\mathit{Prefixes}(L) = \{x \mid \exists\, y \text{ s.t. } xy \in L\}$. Let $L$ be the language of all strings over $\{0,1\}$ that **end in $\mathtt{0}$**. Observe that for any string $x$, we can choose $y = \mathtt{0}$ so that $xy$ ends in $\mathtt{0}$ and thus $xy \in L$. Therefore $\mathit{Prefixes}(L) = \Sigma^*$.
