Define the transformation $\mathit{Suffixes}(L) = \{y \mid \exists\, x \text{ s.t. } xy \in L\}$. Let $L$ be the language of all strings over $\{0,1\}$ that **end in $\mathtt{0}$**. Observe that $y \in \mathit{Suffixes}(L)$ iff there exists $x$ such that $xy$ ends in $\mathtt{0}$: - If $y = \varepsilon$, choose $x \in L$ (e.g., $x = \mathtt{0}$). So $\varepsilon \in \mathit{Suffixes}(L)$. - If $y$ ends in $\mathtt{0}$, choose $x = \varepsilon$. So $y \in \mathit{Suffixes}(L)$. - If $y$ ends in $\mathtt{1}$, then $xy$ ends in $\mathtt{1}$ for any $x$, so $y \notin \mathit{Suffixes}(L)$. Therefore $\mathit{Suffixes}(L) = L \cup \{\varepsilon\}$ = strings that either are empty or end in $\mathtt{0}$. Construct a DFA for this language.
