Assume we have the alphabet $\Sigma = \{0, 1\}$ and let $n = 2$ (a fixed constant). Provide a regular expression for the following language: $$\{ \mathtt{0}^n w \mathtt{1}^n \mid w \in \Sigma^* \}$$ That is, all strings that start with exactly $n = 2$ zeros and end with exactly $n = 2$ ones, with any binary string in between. For example, $\mathtt{0011}$, $\mathtt{000011}$, $\mathtt{001011}$, and $\mathtt{0010111}$ are in the language, but $\mathtt{011}$, $\mathtt{001}$, $\mathtt{0111}$, and $\mathtt{00110}$ are not. *Note: For any fixed $n > 1$, this language is regular — despite superficially resembling $\{0^n 1^n \mid n \geq 0\}$, which is not regular. The key is that the prefix and suffix lengths are **fixed constants**, not variables.*
00(0+1)*11 The string must start with exactly $\mathtt{00}$ and end with exactly $\mathtt{11}$. Any binary string can appear between them. Since $n$ is a fixed constant (not a variable), $\mathtt{0}^n$ and $\mathtt{1}^n$ are just fixed prefix/suffix strings. The language is $\underbrace{\mathtt{00}}_{\mathtt{0}^n} \cdot \Sigma^* \cdot \underbrace{\mathtt{11}}_{\mathtt{1}^n}$, which is trivially regular.
