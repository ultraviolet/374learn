Assume we have the alphabet $\Sigma = \{0, 1\}$. Provide a regular expression for the following language: $$\{ w \in \Sigma^* \mid w \text{ does not contain either } \mathtt{001} \text{ or } \mathtt{110} \text{ as a substring} \}$$ As an example, $\varepsilon$, $0$, $1$, $01$, $10$, $010$, $101$, $0100$, and $10011$ are in the language, but $001$, $110$, $0011$, $1100$, and $11010$ are not.

So a run of length $\geq 2$ can only appear at the end of the string. The string alternates between single $0$s and single $1$s, with at most one long run (of $0$s or $1$s) at the end. Build a DFA with states tracking whether the last run has length 1 or $\geq 2$.
