For regular language transformation problems, it's important that you fully understand the transformation in question. A good first step is to think about a very simple language and consider what strings are accepted by the transformed language. Consider the following language transformation: The function $\mathit{compress}(w)$ takes a string $w$ as input, and returns the string formed by compressing every run of $0$s in $w$ by half. Specifically, every run of $2n$ $0$s is compressed to length $n$, and every run of $2n + 1$ $0$s is compressed to length $n + 1$. For example: - $\mathit{compress}(11000010) = 110010$ (the run of four $0$s becomes two $0$s, the single $0$ stays) - $\mathit{compress}(00010) = 010$ (the run of three $0$s becomes two $0$s) We define the language transformation as: $$L' = \{w \in \Sigma^* \mid \mathit{compress}(w) \in L\}$$
Suppose that $L = \{ 10 \}$. What strings are contained in $L'$? 10 100 01 001 1000 010 **Explanation:** We need strings $w$ such that $\mathit{compress}(w) = 10$. - $\mathit{compress}(10) = 10$ ✓ (single $0$ stays) - $\mathit{compress}(100) = 10$ ✓ (two $0$s compress to one $0$) - $\mathit{compress}(01) = 01$ ✗ - $\mathit{compress}(001) = 01$ ✗ (two $0$s compress to one $0$) - $\mathit{compress}(1000) = 100$ ✗ (three $0$s compress to two $0$s) - $\mathit{compress}(010) = 010$ ✗
