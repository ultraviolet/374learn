For regular language transformation problems, it's important that you fully understand the transformation in question. A good first step is to think about a very simple language and consider what strings are accepted by the transformed language. Consider the following language transformation: We define the language transformation as: $$L' = \{w \mid ww \in L\}$$ In other words, a string $w$ is in $L'$ if and only if $w$ concatenated with itself is in $L$. For example: - If $w = 01$ and $ww = 0101 \in L$, then $w \in L'$ - If $w = 10$ and $ww = 1010 \in L$, then $w \in L'$ - If $w = 0$ and $ww = 00 \in L$, then $w \in L'$
Suppose that $L = \{ 0101, 1010, 00, 1111 \}$.
