For regular language transformation problems, it's important that you fully understand the transformation in question. A good first step is to think about a very simple language and consider what strings are accepted by the transformed language. Consider the following language transformation: The function $\mathit{delete0}(w)$ takes a string $w$ as input, and returns the string formed by removing all $0$s from $w$. For example: - $\mathit{delete0}(11000010) = 1111$ (all $0$s are removed) - $\mathit{delete0}(00010) = 1$ (all $0$s are removed) - $\mathit{delete0}(111) = 111$ (no $0$s to remove) We define the language transformation as: $$L' = \{w \in \Sigma^* \mid \mathit{delete0}(w) \in L\}$$
Suppose that $L = \{ 11 \}$. What strings are contained in $L'$? 11 011 101 110 0011 10 01 111 **Explanation:** We need strings $w$ such that $\mathit{delete0}(w) = 11$. - $\mathit{delete0}(11) = 11$ ✓ (no $0$s to remove) - $\mathit{delete0}(011) = 11$ ✓ (remove leading $0$) - $\mathit{delete0}(101) = 11$ ✓ (remove middle $0$) - $\mathit{delete0}(110) = 11$ ✓ (remove trailing $0$) - $\mathit{delete0}(0011) = 11$ ✓ (remove leading $0$s) - $\mathit{delete0}(10) = 1$ ✗ - $\mathit{delete0}(01) = 1$ ✗ - $\mathit{delete0}(111) = 111$ ✗
