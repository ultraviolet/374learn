For regular language transformation problems, it's important that you fully understand the transformation in question. A good first step is to think about a very simple language and consider what strings are accepted by the transformed language. Consider the following language transformation: For a string $w$, we define $w^R$ as the reverse of $w$. For example, if $w = 0110$, then $w^R = 0110$. We define the language transformation as: $$L' = \{w \in \Sigma^* \mid w^R \in L\}$$ In other words, a string $w$ is in $L'$ if and only if reversing $w$ gives a string in $L$. For example: - If $w = 010$ and $w^R = 010 \in L$, then $w \in L'$ - If $w = 0110$ and $w^R = 0110 \in L$, then $w \in L'$
Suppose that $L = \{ 10, 110 \}$.
