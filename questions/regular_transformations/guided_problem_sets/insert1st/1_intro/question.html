For any non-empty string $w$, let $\mathsf{Delete1st}(w)$ denote the string obtained by deleting the **entire first maximal run** of identical symbols from $w$. For example: - $\mathsf{Delete1st}(001100) = 1100$ (delete the initial run $00$) - $\mathsf{Delete1st}(111010) = 010$ (delete the initial run $111$) - $\mathsf{Delete1st}(1) = \varepsilon$ (the whole string is one run) We define: $$\mathsf{INSERT1ST}(L) = \{ w \in \{0,1\}^* \mid w \neq \varepsilon \text{ and } \mathsf{Delete1st}(w) \in L \}$$ In other words, $\mathsf{INSERT1ST}(L)$ contains all non-empty strings $w$ such that deleting the first maximal run of $w$ yields a string in $L$. For example, with $L = \{1\}$: - $\mathsf{Delete1st}(01) = 1 \in L$, so $01 \in \mathsf{INSERT1ST}(\{1\})$ - $\mathsf{Delete1st}(001) = 1 \in L$, so $001 \in \mathsf{INSERT1ST}(\{1\})$ - $\mathsf{Delete1st}(10) = 0 \notin L$, so $10 \notin \mathsf{INSERT1ST}(\{1\})$ - $\mathsf{Delete1st}(11) = \varepsilon \notin L$, so $11 \notin \mathsf{INSERT1ST}(\{1\})$
