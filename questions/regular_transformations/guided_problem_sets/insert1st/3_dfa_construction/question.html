For any non-empty string $w$, let $\mathsf{Delete1st}(w)$ denote the string obtained by deleting the **entire first maximal run** of identical symbols from $w$. Given a language $L \subseteq \{0,1\}^*$, we define $$ \mathsf{INSERT1ST}(L) = \{ w \in \{0,1\}^* \mid w \neq \varepsilon \text{ and } \mathsf{Delete1st}(w) \in L \} $$ --- We assume that we have a DFA $M = (Q, \{0,1\}, \delta, s, A)$ that accepts $L$. Using this, we will construct a **DFA** $M' = (Q', \{0,1\}, \delta', s', A')$ that accepts $\mathsf{INSERT1ST}(L)$. In the previous question, you practiced constructing $M'$ given a concrete $M$. Now, generalize the transformation to an abstract $M$.
