Consider the following recursively defined function: $$\mathsf{grow}(w) = \begin{cases} \varepsilon & \text{if } w = \varepsilon \\ \mathbf{1} \cdot \mathsf{grow}(x) & \text{if } w = \mathbf{0}x \\ \mathbf{01} \cdot \mathsf{grow}(x) & \text{if } w = \mathbf{1}x \end{cases}$$ We want to prove: $\#(\mathbf{0}, \mathsf{grow}(\mathsf{grow}(w))) \geq \#(\mathbf{0}, \mathsf{grow}(w))$ for all $w$. **Induction hypothesis:** For all strings $x$ with $|x| < |w|$, $\#(\mathbf{0}, \mathsf{grow}(\mathsf{grow}(x))) \geq \#(\mathbf{0}, \mathsf{grow}(x))$. Now consider the **base case**: $w = \varepsilon$. Put the following steps in the correct order to prove the base case. $\#(\mathbf{0}, \mathsf{grow}(\mathsf{grow}(w))) = \#(\mathbf{0}, \mathsf{grow}(\mathsf{grow}(\varepsilon))) \quad$ (because $w = \varepsilon$) $= \#(\mathbf{0}, \mathsf{grow}(\varepsilon)) \quad$ (by definition of $\mathsf{grow}$: $\mathsf{grow}(\varepsilon) = \varepsilon$) $= \#(\mathbf{0}, \mathsf{grow}(w)) \quad$ (because $w = \varepsilon$) $= \#(\mathbf{0}, \varepsilon) \quad$ (by definition of $\mathsf{grow}$: $\mathsf{grow}(\varepsilon) = \varepsilon$) $= 0 \quad$ (by definition of $\#$) $\#(\mathbf{0}, \mathsf{grow}(\mathsf{grow}(w))) = \#(\mathbf{0}, \mathsf{grow}(w)) \quad$ (by induction hypothesis)
